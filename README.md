# Project-Work-Blinky-Board
I made a blinky board using easyeda,editor making a 3d fab. Learning from small stuffs
A simple PCB project created using EasyEDA to build a “blinky” circuit—an LED that turns on and off at a fixed interval. The design includes a basic oscillator (typically using a timer IC like 555 or a microcontroller), current-limiting resistor, and power supply connections. The repository contains the schematic, PCB layout, and Gerber files, making it easy to review, modify, or manufacture the board. Ideal as a beginner project for learning PCB design, circuit basics, and hardware prototyping 

 STEPS Done here -;
1. Defined the goal: design a simple LED “blinky” circuit with a steady on/off pattern.
2. Chose components: used a timer IC (like 555), resistors, capacitor, LED, and power source based on required blinking frequency.
3. Created schematic in EasyEDA: placed components and connected them according to the circuit design.
4. Simulated the circuit: verified the LED blinking behavior and adjusted resistor/capacitor values if needed.
5. Converted to PCB layout: arranged components on the board and routed traces properly.
6. Designed board outline: set dimensions and ensured proper spacing and clearances.
7. Ran design rule check (DRC): fixed errors like overlapping traces or incorrect connections.
8. Generated Gerber files: prepared files required for PCB manufacturing.
9. (Optional) Ordered PCB: uploaded Gerber files to a manufacturer.
10. Assembled and tested: soldered components onto the PCB and verified that the LED blinks correctly.
